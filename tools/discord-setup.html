Discord setup for Helmian (5 minutes)

You only need Discord. Slack is skipped. GitHub is already wired on this PC.

1. Open Discord Developer Portal

https://discord.com/developers/applications — log in if asked.

2. New Application → name it Helmian

OAuth2 → Redirects → Add:

https://helmian.vercel.app/api/team-oauth/discord/callback

Scopes for OAuth URL generator: identify + guilds

3. Bot tab

  • Add Bot → Reset Token → copy token
  • Enable Message Content Intent
  • OAuth2 URL Generator: scopes bot, permissions View Channels + Read Message History (value 66560) → invite to your server

4. Paste into env file

Open %LOCALAPPDATA%\Helmion\team-connectors\local-service.team.env and set:

HELMION_DISCORD_CLIENT_ID=...
HELMION_DISCORD_CLIENT_SECRET=...
HELMION_DISCORD_BOT_TOKEN=...

Then run Start-Demo-Desk and press Connect Discord in Helmian.
