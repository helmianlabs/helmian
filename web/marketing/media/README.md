# Marketing media

Place approved public demo files here, or use an approved HTTPS media URL.
Then add the `src`, optional `poster`, and optional `caption` in
`../site-config.js`. Empty values intentionally render a labeled placeholder.

Suggested filenames:

- `helmian-desktop-overview.mp4`
- `helmian-guard-review.mp4`
- `helmian-project-flow.mp4`

Do not place raw recordings here until project names, notifications, account
details, file paths, and other screen content have been reviewed for publication.

Current approved web copies:

- `helmian-desktop-overview.mp4` and `.jpg`
- `helmian-guard-review.mp4` and `.jpg`

These are web-optimized derivatives. The original recordings remain in the
user's recording folders and are not modified by the site build.
