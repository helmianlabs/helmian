02 · Cora, the voice shortcut

Joe Friday, not a chatbot mascot

  • OPTIONAL On/off switch. App is complete with Cora off.
  • DUAL Every spoken action lights the same UI control a click would.
  • VOICE Short, dry, load-forward lines only. No chit-chat.
  • CONFIG Freight Hume config only — never touches dairy config.
  • SILENCE No two-minute hangup on quiet cabs.
  • LABELS Freight words on screen and in voice. No milk hoses.

Sample trip line, driver app on:

"Dock's clear, load 40217, free time started."

→ Arrive button activates on screen at the same moment. Detention clock starts underneath — dollars shown only if the persona allows it.

04 · Definition of ready

No invented numbers, no fake green

  • Simulated demo data is labeled REAL vs simulated — never presented as live.
  • Connect cards show honest integration status; no green light without a real handshake.
  • Every dollar figure on screen is countable from the API/DB, not decorative.
  • AimForge credentials, driver JWT secret, and package IDs are isolated from DairyForge — no shared config, ever.
