Cora Build Studio

Make a bounded page, dashboard, or workflow request through Cora’s governed receipts.

  1. Describe a request to create a draft.
  2. Record a bounded revision.
  3. Record an owner/admin approval decision.
  4. Queue an approved revision against a registered workspace project.

Queueing is not execution. A queued request does not execute until a verified GitHub source binding and a real worker runtime exist. This studio does not verify a source, make a checkout, change files, publish, or deploy.
