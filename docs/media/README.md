# Product screenshots

Current screenshots of the real product, captured from the live app at
helmian.cloud. These are screen captures of the product as it stood on
the date in each filename — not mock-ups, not recreations. When a
surface changes in a way a screenshot here no longer shows honestly,
replace the file in the same push that ships the change.

Brand assets (the logo, the hero animation) live in `docs/assets/`;
this folder is for screenshots of the running product.
