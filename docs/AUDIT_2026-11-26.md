## 3. Things that confuse a first-time developer

Fixed in this PR:

- The README was 538 lines of product history. It is now a short developer
  front page; the long version moved, unchanged, to `docs/PRODUCT_TOUR.md`.
- No list of entry points, hooks or environment variables: added
  `docs/ENTRY_POINTS_AND_HOOKS.md` and `docs/CONFIGURATION.md`.
- 106 docs with no index: added `docs/README.md`.
- No `SECURITY.md`: added.
- `PRIVACY.md` said the PC spoke "has no free shell". Since 2026-10-31 it
  also runs free-text PowerShell, always behind a human approval. Corrected.
- The voice description said no text leaves the browser tab; the app calls
  Helmian's own voice server first. Corrected in `docs/PRODUCT_TOUR.md`.
- `npm run test:hands` and `npm run test:discord-bridge` failed on Node 22+
  because `node --test test/` no longer accepts a folder. Changed to
  `test/*.test.mjs` (the form CI already uses).
- `docs/demos/README.md` linked to `sandbox://` paths that do not exist.
  Pointed at the files that are in `docs/demos/`; the audio files are marked
  as not in the repo.
- `credential-service-image/` had no explanation: added a README warning
  that its one-off scripts write to production.

Found and left alone:
