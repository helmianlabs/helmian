### Voiceover script

I'm Troy. I'm 53. When I was 10, my mom bought me a TRS-80 and I learned to code. I've been building ever since.

Last year I was running Claude for my work and it kept hallucinating. Making things up. Cutting corners. I got frustrated enough to build the solution myself.

That's Helmian. It's a governance layer for AI agents. Every action goes through approvals. Every write gets a lease so agents don't step on each other. Everything is audited.

I didn't set out to build a company. I set out to stop my AI from lying to me.

Now it's a platform. Agents as team members in chat, coordinated by a Maestro, watched by Guard. If you've been burned by AI cutting corners, Helmian is for you.
