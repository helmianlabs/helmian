## READ THIS BEFORE YOU COMMIT — the git index is shared, and a pathspec does not save you

Measured 2026-07-30 by two sessions independently, ninety seconds apart. This
corrects advice that had been given to every session that night.

**`git diff --cached --name-only` proves what is in the index at the instant you
read it. The race lives between that read and your commit.** Both sessions ran
that check, saw exactly their own files, and committed anyway carrying the
other's work. One commit picked up two files belonging to a session that had
staged them in between. The check is not wrong; it is just not a lock.

**`git commit -- <paths>` commits the WORKING TREE version of those paths and
DISCARDS whatever you staged for them.** This is the part that surprises people.
It means a partial-hunk stage and a pathspec commit **cannot be combined**:

```
git apply --cached one-hunk.patch     # stages your hunk only
git commit -- path/to/file            # ignores it, commits the whole working file
```

So there is no combination that is safe by itself:

| What you do | What you get |
|---|---|
| `git commit -m …` (no pathspec) | everything in the index, including a neighbour's staged files |
| `git commit -- <paths>` | the working-tree version of those paths, discarding your staged hunk |
| `git apply --cached` + bare commit | your hunk **plus** whatever else is in the index |

**The mitigation is not a flag. It is: land shared files fast and small.** Stage
and commit in one motion, keep the window tiny, and if you do carry a
neighbour's file, say so plainly afterward rather than rewriting history — a
`git reset --soft` on a branch several sessions are committing to can destroy a
commit landing in the same second, which is worse than wrong attribution.

Two specific traps behind this, both real:

- **A pathspec cannot reach an untracked file.** If your change adds a new file,
  `git add` that one path first, and make that the only index write you make.
- **Committing a shared file wholesale can break the build for everyone.** On
  2026-07-30 `SmokeTests/Program.cs` briefly held two sessions' registration
  lines while one session's checks class was still untracked. Committing that
  file would have put a reference to a class git did not have into `main`.
